# 对标视频拆解

> concept 阶段读取。用户提供参考视频时必须先完成本步；参考视频是**约束来源**，不是风格词来源。

## 为什么必须先拆

直接对参考片说“照这个风格”，得到的是形容词，不是可执行的机位、光源和切点。拆解的目的，是把参考片里可复用的**结构**（节奏、景别序列、光源逻辑、切点与音乐的关系）提取成 `design.json` 的具象约束，同时把**内容**（人物、剧情、道具）明确排除，避免抄镜头。

## 怎么拆

1. **先完整看一遍**，不暂停。记录整体节奏与情绪曲线：哪里起、哪里压、哪里放。
2. **第二遍逐段暂停**，按镜头记录：时间码、时长、景别、机位高度、运镜、主光方向与色温、人物调度、切镜动机。
3. **统计**：镜头数、平均镜长、景别序列、切点与人声重音的对齐关系、转场类型（硬切/叠化/黑场）。
4. **分类**：把结论分成两栏——可迁移的结构项、不可迁移的内容项。

抽帧只能看清单个静帧，不能替代观看；只看缩略图墙不算拆解完成。

## 写到哪

写进 `state/concept.json` 的 `baseline` 字段，不新建文件：

```json
{
  "baseline": {
    "source": "input/reference.mp4",
    "sha256": "<实际文件指纹>",
    "reviewed": true,
    "coverage": "0:00-3:20 完整观看；未做逐帧字幕核对",
    "shot_stats": {
      "shot_count": 48,
      "avg_len": 3.2,
      "size_sequence": ["远景", "中景", "近景", "特写"],
      "cut_offset_to_beat": "-0.1s"
    },
    "rhythm": "主歌 4s/镜，副歌前 2 秒开始加速，结尾单镜收",
    "transferable": ["主光恒定来自画面左上", "黑场 0.3s 分场", "副歌重音处硬切"],
    "not_transferable": ["人物造型", "剧情线", "具体道具"],
    "design_constraints": ["全片主光方向统一", "切点对齐人声重音 ±0.1s"]
  }
}
```

字段含义：

| 字段 | 要求 |
|---|---|
| `reviewed` | 只有实际完整观看后才可写 `true`；抽帧、缩略图、他人转述都不能算 |
| `coverage` | 写明看了哪段、没看什么；未核对的项写在后面 |
| `shot_stats` | 镜头数与平均镜长必须是实测计数，不能估 |
| `transferable` | 只写结构项，且必须能落成 `camera` / `cut_reason` / `lighting` / `scenes` 的具体值 |
| `not_transferable` | 显式声明不进入提示词的内容，防止后续抄镜头 |

## 怎么落到设计

| 拆解结论 | 落点 |
|---|---|
| 平均镜长、节奏 | `design.json` 每个镜头的 `start` / `end` 分配，`cut_reason` 写清节奏依据 |
| 景别序列、机位高度 | `shots[].camera` |
| 主光方向、色温、明暗区 | `scenes.<ID>.lighting`、`shots[].lighting` |
| 切点与音乐关系 | `cut_reason` 与音乐窗口的对应 |
| 空间与调度 | `shots[].blocking`、`scenes.<ID>.geography` |

`not_transferable` 中的内容不得出现在 `action`、`camera`、`lighting` 或提示词里。

## 边界

- 参考视频只提供结构约束，不复制具体镜头、人物和剧情。
- 没有 `baseline` 也可以继续做片，但此时设计没有外部参照，属于纯原创路径；写了 `baseline` 就必须通过本文件的字段要求。
- 拆解结论与 ZY Scene Master 冲突时，以用户锁定与硬事实为先，其次才是参考结构。
