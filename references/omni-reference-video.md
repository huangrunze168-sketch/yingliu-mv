# 多模态全能参考视频 · ZY 导演提示词编译规范

新项目执行顺序以[当前实际执行流程](actual-execution-workflow.md)为准；本文件说明对应阶段的细节。

## 1. 全能参考是什么

全能参考（omni reference）是一次请求同时接收文字、图片、视频和音频，让模型按指令分别借用其中的人物、服装、场景、构图、动作、运镜、声音或节奏。它不是“上传一张人物图作为首帧，让图片动起来”，也不是必须先把人物放进 Subject Library。

官方能力依据：

- Seedance 2.0 官方说明支持文字、图片、视频、音频组合输入，并参考构图、动作、运镜与声音；15 秒内可输出多镜头。
- Seedance 2.5 官方说明支持单次最多 30 张图片、10 段视频、10 段音频，最长 30 秒，支持时间戳、多主体、多场景和多镜头叙事。
- Lovart 的模型 schema 由适配器在提交前读取。2026-10-13 快照中，Seedance 2.5 暴露 `image_list / video_list / audio_list / omni_reference_task_type`；MiniMax-H3 暴露 `image_list / video_list / audio_list`，但输入数量和时长不同。

官方资料：

- https://seed.bytedance.com/zh/blog/seedance-2-0-%E6%AD%A3%E5%BC%8F%E5%8F%91%E5%B8%83
- https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5

## 2. ZY 如何进入全能参考

ZY 不替代模型 API，而是提供四层可执行信息：

1. `Scene Master`：每镜真实空间、光源、人物意图、阻力、摄影机站位和观众信息。
2. `Continuity Bible`：跨镜固定人物、服装、地点拓扑、方向轴、道具状态与来源光。
3. `Shot Delta`：相对上一镜真正发生的变化，不重复设计整套世界。
4. 导演四轴：把导演方法翻译为光线、曝光、摄影机与空间决定；导演姓名不进入后端提示词代替执行。

编译后端提示词时，先写素材职责，再写全章导演规则，最后写分时镜头。参考素材和文字命令必须一一对应。

## 3. 素材职责表

推荐的单章引用方式：

```text
@图片 1：只参考女主五官比例、发型、耳饰和白色汉服的版型、纹样、层次；不参考背景、姿势、构图和灯光。
@图片 2：只参考房间 Scene Master 的门窗地理、桌案位置、木纸材质与来源光。
@图片 3：只参考镜头 A 的构图起点、人物站位和视线关系；人物身份仍服从 @图片 1。
@视频 1：只参考克制的手持步态与遮挡切换，不参考其中人物、服装和场景。
@音频 1：只参考本章演唱进入点、动作节奏和切点，不改编或替换最终母带。
```

同一素材不要笼统写“全部参考”。人物参考与场景参考冲突时，人物身份服从人物图，场景地理服从 Scene Master；分镜关键帧不得覆盖人物锁。

## 4. 分时多镜提示词骨架

```text
16:9 写实叙事音乐 MV，15 秒生成包，包含四个独立剪辑镜头，不是一镜到底。固定为 @图片 1 的同一人物和同一套服装。

【素材职责】
（逐项写 @图片/@视频/@音频 的参考范围与禁止继承项）

【连续性硬锁】
门在画面东侧，桌案靠北墙；月光只从东窗进入；旧信从右手转入袖内后不得复位；人物始终是 @图片 1。

【分时镜头】
0.0–3.2 秒：门内远景。摄影机位于门柱内侧腰高，人物从暗部走向桌案；门框先遮住半身，脚步停下时切。
3.2–6.0 秒：桌沿手部近景。切到轴线同侧，指腹压住旧信翘起的折角；纸受力后才平伏。折角完全贴桌时动作匹配切。
6.0–10.4 秒：侧后中景。人物拿起信，视线先落在墨迹，再转向门外空路；摄影机不追脸，门外亮区成为第二信息层。视线离开信时切。
10.4–15.0 秒：门外反向中远景。人物跨过门槛，将信收入右袖；衣袖因迈步滞后，停在廊柱阴影边缘。结束状态：人已在门外，信已入袖，门和光源位置不变。

【衔接规则】
每次切换都由可见动作或视线触发；相邻镜头保持轴线、手部占用、道具位置和光向连续。不得用同一构图的数字推拉代替切镜。

【成片限制】
不做人物写真、服装广告、无来源轮廓光、装饰雾、塑料皮肤或无因果变形转场；嘴部只在指定演唱段可见并服从 @音频 1。模型音轨不作为交付母带。
```

## 5. 导演模式不是风格词

每个镜头都要回答：摄影机能站在哪里、观众先看到什么、人物想完成什么、什么阻碍它、画面在何种可见变化时切走、下一镜怎样接住状态。若删除“电影感、唯美、某导演风格”后仍能执行拍摄，提示词才算完成。

当前 MV 的修复方向应是：一个 12–15 秒生成包包含 3–5 个剪辑镜头；同一章可以在相连空间之间移动，也可以通过动作匹配、视线匹配、遮挡切或声画提前进入衔接。场景变化必须来自故事路径和地点拓扑，不能为了多样性随机换景。

## 6. V1.6.1 提交与审片时间约定

提交契约的 `edit_shots[]` 每镜提供唯一非空 `id` 和 `start_sec / end_sec`（或 `window.start / window.end`）。时间必须有限、非负、正向且相邻连续，倒序、重叠或空洞阻断。单个提交包统一使用同一时间基准。

`director_review.timecoded_findings` 使用样片章节相对秒数，从0开始，`end_sec` 不得超过该章节 `duration_sec`（没有时从 `window` 计算）。整曲时间码必须先转换成样片相对时间。
