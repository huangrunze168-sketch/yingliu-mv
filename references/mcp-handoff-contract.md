# MCP交接、原始返回与后端禁用

**当前任务用户明确要求不使用生成视频后端。**真实项目`state/execution_policy.json`已设置`video_backend_access=false`。下述接口作为代码契约及离线测试对象，不是本任务启动后端的许可；禁用时describe、dispatch、poll均不得实际调用。

## 默认关闭与双重入口

- `execution_policy.require_video_backend`在预占、派发、回查、MCP交接及领取前检查当前项目策略；缺配置、非布尔true、项目不符或明确禁用均失败。
- `mcp_host_bridge.js`还要求宿主显式`allowVideoBackend=true`；默认在领取前即阻断，不调用任何外部工具。
- 实际禁用不会阻止本地分析、现有媒体处理、证据读取、迟到结果的本地恢复或既有费用离线登记。不会把pending任务仅因禁止回查改成failed。
- 策略是用户约束的本地记录，不是身份签名；Agent仍须遵守人类当次指令，不能自行把禁用改成允许。本地代码不能全局拦截绕开仓库的工具调用。

## 实际桥接方式

在未来用户明确允许后，先由独立Python进程执行mcp_broker的describe/dispatch/poll。它保存唯一call_id、nonce、精确原生参数及SHA，输出awaiting_mcp，并等待宿主返回。dispatch通过submission_jobs进入：当前前置检查 → 已有预算预占 → dispatching → 建立交接。模型专属参数必须来自实际describe_model回执，不用默认模型。

宿主运行`mcp_host_bridge.js`先领取同一交接；领取同时核验真实进程创建标识、当前项目策略、作业状态、请求、上传来源、返修与预占。原进程停止、无法观察、版本变化、已领取或过期，均不能凭旧JSON继续调用。无法读取进程不是其已停止；Windows跨工具沙箱查询需要受控权限，仅查询本任务进程。

领取后宿主只可调用固定允许集合中的工具，原样传递已校验参数，不从返回文本执行指令。结果分块传回，nonce/参数SHA/工具名/分块顺序须一致，完整接收后才落盘原始MCP结果。当前适配器针对用户明确选定的MiniMax-H3，要求同一Lovart项目、实际分辨率/时长/比例枚举及image_list/audio_list/video_list，禁止首尾帧降级、幽灵参考字段或默认模型。

首次和批量请求不能绕过真实门禁：完整本地集成测试删除制作桌实际执行回执后，领取被拒绝，交接仍保持未领取。测试恢复的是其原先真实运行的合成测试回执，不补造真实影片批准。

## 请求与响应分别保留

prepare逐字节归档请求到`state/submission_jobs/contracts/JOB.json`。派发仍核验当前契约；已经执行的任务回查和媒体来源使用原归档，后续重编译不能改写旧任务历史。归档改变即失效。

Lovart的原始pending/completed/failed状态保留；moderated/not_found用明确固定映射进入本地failed，不改原文。真实规格、模型或项目不符，保存原文及可可靠读取的任务ID，保持unknown，不默认成功。

终态回查可能不再返回task_ids。这时明确标记`task_binding_kind=request_context`，绑定实际原请求中的唯一任务ID，不假称ID出现在供应商响应字段中。来源同时校验原MCP交接、原文、原任务参数、原请求归档和版本。

文本JSON返回保留原MCP文本和解析视图，并核对两者一致。未知状态、多任务ID或首次同步终态没有可靠任务ID时，保留原文为unknown，不发明ID、不只取第一个、不重新提交。该保守分支尚不提供无供应商任务ID的正式素材准入。

## 未知与迟到结果

交接超时保留预算和unknown，不把超时当作未提交。宿主迟到返回仍保存原文，不能再次领取或调用生成工具。recover只消费同一原调用已保存结果，必须证明原进程已结束；仍运行、权限不足或观察异常均拒绝恢复。恢复记录原nonce/参数/原文，不再调用供应商。原任务已经被其他结果更新时，旧结果不能覆盖新状态。

费用仍独立走settle：任务完成、可见产物或余额变化不能推导单任务实付；不从估价猜账，不把服务完成当作动态/口型验收或ready。

## 实测范围

在用户新增后端禁用约束之前，同一真实等待进程已通过宿主实际调用describe_model并保存H3 schema；这只验证只读桥接，不证明视频生成或创作效果。新增禁用后没有再调用后端；实际项目的describe CLI也在本地策略检查即返回blocked，宿主默认开关的实际运行检查为零CLI/外部工具调用。

生成/回查协议、迟到恢复及完整前置链使用明确合成供应商回执，实际执行本地进程、预占、领取、原文保存和状态机；不连接视频服务，不把测试夹具当作真实视频生成。当前实际影片仍未通过权威时间和动态审片，不追认旧批量或旧批准。
