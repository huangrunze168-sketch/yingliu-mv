# 对话问题复盘与修复索引 · 2026-10-12

本文件整理本次真实 MV 试产暴露的问题。它记录产品与工作流缺陷，不保存凭证，也不把生成成功等同于审美成功。

| BUG-18 | 人物参考图污染构图、背景和灯光 | 未严格分离 Reference Role | 人物图只锁 `likeness + wardrobe`；场景、构图和光线来自 Scene Master |

| BUG-26 | AI 味由形容词和负面词处理 | 缺少动作重量、信息层级、材质受光和因果切镜 | Scene Master 新增强制字段：`visual_center / information_hierarchy / gaze_target / action_physics / material_response / edit_trigger` |
| BUG-27 | 未审片就并行生成四章 | 把吞吐量优化置于导演判断之前 | `chapter_plan_build.py` 自动选代表章；`generation_plan.json` 默认只允许该章 |
| BUG-28 | 联系表代替动态审片 | 静帧无法评价表演、运动、剪辑和口型 | `director_review_gate.py` 要求完整观看并提交九项可观察证据 |
| BUG-29 | 技术 PASS 被当作成片 PASS | 容器、时长、音轨与艺术质量没有分层 | 导演门禁独立于技术检查；未批准只能输出文件名带 `preview` 的技术预览 |

## 造梦师分镜最小导演契约

V1.4 新增问题与修复：

- BUG-36：一句歌词一镜、景别轮换、后半段假副歌使设计机械。改为音乐引用 visual_edit_plan，导演明确景别/演唱，比例与连续限制为项目配置。
- BUG-37：指定导演但没有场景化决策，通用四轴仍冒充导演方法通过。新增实际来源文件、强度、激活轴、逐镜理由与观察依据，缺失时阻断。
- BUG-38：参考图职责、视觉语法与故事事实混在一起。development 分开来源台账/参考职责/视觉规律，人物图严格只管身份与服装。
- BUG-39：场景与关键帧缺少版本依赖，母版换了仍沿用旧帧。资产登记绑定同场景母版与相关设计指纹，变更报告需复核而不自动重生成。
- BUG-40：模型生成时长被直接当最终镜头时长。edit_selection 按整数帧选取已审素材，edit_assemble 本地裁切后才进入 V1.4 正式合成。
- BUG-41：样片批准缺少段落判断与版本绑定。增加节奏/情绪/切镜/视觉语法四项证据，绑定实际媒体与制作依赖。
- BUG-42：歌词行内切镜后要求重新唱完整歌词。逐镜保存多行文本上下文和相交歌词窗口，实际口型只服从裁切音频。

BUG-35：合成音质明显低于用户原曲。真实项目 `source_audio=input/song_16k.wav`，使 44.1 kHz 双声道 MP3 被替换为 16 kHz 单声道分析副本后再次有损编码。修复为独立 `master_audio`、原音频流复制/无损合成；采样率、声道与音频载荷逐项验证。对齐三验不等于音质保真。

## V1.4.1 真实试产新增问题

- BUG-43：关键帧把“回屋、合匣、移手”等连续动作同时画进一个瞬间。根因是静帧编译直接消费 `current_action`。修复为强制 `keyframe_moment`，整段过程继续留在 `motion_design`。
- BUG-44：逐镜虽有导演四轴，仍可能没有真实拍摄站位与取景边界，回图变成漂亮正面写真。修复为强制 `story_intent / obstacle / audience_information / shooting_station / frame_boundary / visual_acceptance`，并写入关键帧制作包和关5。
- BUG-45：自己生成的 AI 场景图同时被当作摄影质感证据，形成自我认证。修复为资产登记只证明静态结构已观察，显式分开 `agent_inspected / user_accepted / dynamic_verified / quality_claim`。
- BUG-46：临时 ASR 时间在全部歌词待核时仍可能继续准备正式口型章节。修复为 `production_timing_verified=true` 硬门禁；provisional、fallback、simulation 和非空 pending 均阻断。
- BUG-47：补充的回望/手部镜没有独立时间和口型职责，可能在后端阶段临时混入。修复为 `coverage_plan` 候选制；选中后必须先物化为 visual_edit_plan 的正式镜头。
- BUG-48：16:9 意图被误写成“生成结果必然严格 16:9”。修复为区分请求比例、后端实际返回尺寸和最终交付画布；生成器不支持精确尺寸时不得虚报，统一在交付层核验/适配。

## V1.4.2 真实后端试产新增问题

- BUG-49：把提示词文字 `@女主` 当作角色库绑定。实际生成请求没有携带结构化
  Subject/Asset/Mention 标识，后端随机生成了另一人物；重新加入普通图片 URL 又触发真人审核拒绝。
  修复为通用提交契约门禁：必须同时具有已审核状态、角色库绑定种类、稳定资产标识和
  `structured_mentions`，否则提交前阻断；严禁删除人物参考后静默降级生成。
- BUG-50：参考歌曲用于口型时仍开启模型音频输出，导致输出版权策略拒绝，并可能重编码母带。
  修复为条件音频与交付音轨分离：条件音频存在时显式 `generate_audio=false`，最终只重贴原始母带。

## V1.4.3 全能参考与导演剪辑新增问题

- BUG-51：把“后端最多生成 15 秒”误当成“一个剪辑镜头持续 15 秒”，造成整段只有同一场景和同一机位。修复为生成包与剪辑镜头分离；生成包内按时间戳组织多个独立镜头，长镜头必须有导演批准和叙事理由。
- BUG-52：把全能参考误解成固定职责字段集合，并错误要求普通上传图必须先变成角色库 Subject。修复为真实的多模态引用绑定：每个 `@素材` 对应本次请求里的图片/视频/音频资产，并在自然语言中写清参考意图；角色库只是可选入口。
- BUG-53：ZY 的导演四轴只进入结构化记录，没有成为多镜提示词中的观看位置、信息释放、动作触发和切镜关系。修复为 `Scene Master → Continuity Bible → Shot Delta → 分时多镜提示词`，每个时间段都写独立画面决定与状态承接。

## V1.5.0 AI 剧组制新增问题

- BUG-54：连续三个镜头复用同一人物角度、景别和机位高度，画面虽不同却不能构成合格剪辑。修复为机位签名审计，连续三镜相同直接阻断。
- BUG-55：相邻镜头没有 30 度变化或无意跨越 180 度轴线，空间关系混乱。修复为逐镜记录 `angle_deg / camera_side / axis_id`，不足 30 度或跨轴未重置时阻断。
- BUG-56：人物上一镜出画与下一镜入画方向相反，演员动线跳变。修复为调度部门强制记录起止点、入出画与屏幕方向，并做相邻镜头检查。
- BUG-57：整片平均镜长过长，连续慢镜且开场无吸引点。修复为项目 `pacing_policy`，分别检查平均镜长、慢镜连续数、节奏重复和 hook deadline；这些值来自音乐与受众，不来自模型上限。
- BUG-58：场景美术只有背景名，灯光只有“电影感冷暖光”，导致舞美和光线没有叙事能力。修复为场景美术七项与灯光六项交接物，并写入场景母版、关键帧、运动和章节制作包。
- BUG-59：先套王家卫、昆汀或诺兰风格，再用风格掩盖基础语法错误。修复为 `style_application_order=after_film_grammar` 硬门禁，八部门与连续性先通过，导演风格后置。
- BUG-60：把“参考数百部高分电影”误做成下载正片或把具体电影画面塞进提示词。修复为 annotation-only 语料、来源 manifest、匿名聚合画像和禁止具体镜头复刻。
- BUG-61：把电影统计均值当成新的死规则，反而抹平歌曲曲式与创作意图。修复为默认 `advisory`；只有样本量达标且用户显式选择 `enforce_envelope` 才把统计包络设为门禁，基础视听语法仍独立硬审。
- BUG-62：八部门虽有字段却没有交接验收，结果仍然各写各的。修复为 schema 2 部门交接图，关键上下游缺失或没有 `deliverable / acceptance` 即阻断。
- BUG-63：美术和灯光继续使用“唯美、电影感”等形容词。修复为场景历史、色彩脚本、尺度线索、背景活动，以及逐镜光向、光质、补光、实景灯、色温、材质响应和连续性锚点。
- BUG-64：只看平均镜长，仍会出现长时间没有新信息和连续同角度。修复为最大钩子间隔、视觉停滞累计时长、景别覆盖和 reaction/detail、turn/payoff 覆盖角色门禁。

每镜必须回答以下问题，缺项即阻断编译：

1. 发生前是什么状态，当前改变了什么，下一步将被什么触发；
2. 视觉中心是什么，第一/第二/允许模糊的信息分别是什么；
3. 人物身体、手、脚、视线和道具如何占用空间；
4. 动作如何准备、受力、完成并留下余波；
5. 摄影机在现实空间哪里、为什么运动、是否跨轴；
6. 光从哪里来，哪些区域应保持暗，材质如何响应；
7. 这一镜为什么在此处切，而不是因为“音乐到了一个点”；
8. 相比上一镜只允许哪些 Shot Delta，哪些连续性绝不能重置。

提示词不是修辞作文。删除“电影感、大片、唯美、8K、某某导演式”后，如果仍不能画出空间平面、演员走位、光源图和切镜原因，该提示词仍未完成。
