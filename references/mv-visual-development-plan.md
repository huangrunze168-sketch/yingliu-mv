# MV 视觉开发升级方案 · 2026-10-13

状态：V1.4.0 已实施结构契约、音乐引用分镜、分层编译、资产依赖、修复比较与本地剪辑工具；艺术分析和实际图片/动态审查由 Agent/用户执行。本轮未生成媒体，详见 visual-workflow-contract.md。

目标：把 ZY Cinematic Realism 的故事开发、视觉分析、创作语法、连续性、编译与修复真正用于 MV，结合固定人物、场景选优、分镜关键帧和精细视频运动提示词，改善可观察的成片质量。传播效果不作为机器门禁承诺。

## 1. 权威与职责

- 用户锁定：人物五官与服装、16:9、歌曲与原始母带、明确的故事和视觉要求。系统提案不能自行升级成用户已接受的锁。
- 音乐时间轴：音频事实的权威；视觉镜头可以覆盖一句歌词的一部分或跨多行歌词，不能改写歌词/音素时间。涉及口型的裁切由已核验的音频窗口推导。
- Story Source Ledger：记录来源、读过的范围、事实、解释、视觉提案及依赖，不拥有导演风格，也不替代 Scene Master。
- Continuity Bible：记录人物、服装、道具、地点拓扑、光源、知识状态及状态变化。
- Decode Card：记录真实视觉参考中观察到的视觉规律、迁移边界；不拥有故事事实。
- Scene Master：当前画面的唯一场景事实结构。其他记录引用它，不另建互相竞争的场景真相。
- 用户选择的后端：决定可用图像/视频能力、参考输入方式、音频绑定、时长、参数及费用；核心保持模型中立。

## 2. 三条开发链路

### 故事与音乐

母带与歌词 → 音乐结构/情绪标记 → Story Visual Development → Story Source Ledger → 全片导演方案。

全片方案回答：人物想得到什么；遇到什么阻碍；观众最初和最终知道什么；哪个决定承担高潮；意象如何再次出现并改变意义；音乐哪里加压、哪里停顿。叙事、演唱、概念/舞蹈等形式按歌曲与需求选择，不强制所有 MV 都是微电影。

歌词、现有故事和用户要求是来源事实；“等待后决定出关”等新增故事属于候选提案。不得把歌词中的意象自动解释成已发生的剧情事实。

### 参考视觉

真实参考片段/图片 → Reference Role Router → Medium Router → Dream Decode → Core Visual Rules → Transfer Scope → Decode Card。

- 人物图：只管 likeness + wardrobe，不提供场景、构图、光线、姿态或整体风格。
- 场景母版：管地点身份、地理与建筑；允许根据镜头改变视角、人物位置和构图。
- 质感参考：经观察后提取光、曝光、色彩、材质、空间与观看关系，排除其人物、服装、故事、标识和未授权道具。
- 多参考先分配职责；同一职责的参考才分析共性，不平均矛盾方法。
- 每张参考记录实际访问与观看范围。只看静帧不能声称了解原片表演、镜头运动或剪辑。
- 全片保留 5–8 条有证据的核心视觉规律；每镜只选择 3–5 条真正相关的规则。
- 画面漂亮不等于存在 Expression Mechanism；只在观察到具体表达机制时提取。

动态参考的镜头长度、运动、表演和音乐剪辑另外记录为 MV 分析层，不能把静帧 Dream Decode 直接当作视频分析能力。

### 导演与摄影

场景目标 → Director Recommendation Matrix → 2–3 位候选比较 → 主导方法及强度 → Director Four-Axis → 必要的 Style / Cinematography Card → 逐场景决策。

- 推荐按场景目的与观看关系，不按“古风=某导演”匹配。
- 默认一个主导方法；明确混合时，次要导演仅控制一个声明的轴。
- 轻微强度只激活 1–2 个兼容特征；其余轴允许保留，不为了填表制造变化。
- 四轴逐场景落地，不能复制一组全局句子给所有镜头。
- 主导导演已覆盖某维度时，创作卡不重复叠加。只有能解决未决问题且兼容时才使用卡片。
- 对当前候选故事，可比较胡金铨的门槛与路线、张艺谋的秩序与偏离、岩井俊二的小动作与情绪余波。比较结果仍属提案。

每项方法至少说明：来源文件；本场景目标；已锁定与开放维度；激活的特征；对应画面决定；影响的镜头；观察验收依据。导演姓名不进入后端提示词代替执行指令。

## 3. 场景母版与关键帧生产

先设计可用于表演的场景，而不是先生成漂亮背景。

1. 为必要地点画清门窗、通道、道具工作区、摄影机可落位区域、方向轴与光源覆盖。
2. 根据 Scene Master 编译母版提示词。人物出现时使用已锁定身份与服装，场景仍独立设计。
3. 比较候选母版：空间可读、材质受光可信、动作可实现、视觉语法符合已选规则。候选数量服从用户预算，不默认无限重抽。
4. 使用 Remix 固定人物、地点与其他成功事实，每次只改变机位、光线或构图等一个主要变量，比较变化带来的效果。
5. 批准母版后建立 Base Lock；不同机位关键帧由同一母版和地理状态派生，不逐镜重置建筑和光线。
6. Shot Delta 明确动作、视线、机位、道具状态等本镜变化，更新身体与道具占用、阴影和材质后果。
7. 补足剪辑需要的主镜、反应、细节与空间关系镜头；不为景别轮换而增加镜头。

空镜也要有具体叙事或音乐作用。风、月光、落尘等不得成为所有镜头的装饰模板。

## 4. 提示词编译与运动设计

维护三个相关但不同的交付：

| 交付 | 写清什么 | 避免什么 |
|---|---|---|
| 场景母版提示词 | 拓扑、建筑、光源、色彩、材质、可用动作区域 | 把参考人物图背景当作场景 |
| 分镜关键帧提示词 | 一个具体瞬间、人物/服装锁、构图、视线、空间关系、信息层级 | 把连续多个动作塞成一个静帧 |
| 视频提示词 | 起始状态、动作过程、准备/受力/余波、道具接触、机位运动、结束状态及声画意图 | 再次设计画面，或将多个复杂动作并列 |

编译依次保护用户锁、参考职责、场景事实、媒介与相关视觉规律，再转换为用户选定后端的真实表达方式。档案记录不全量粘贴进提示词，精细意味着关系明确和优先级清楚。

示例：同一人物站在已确认的门内阴影中，右手握旧信；视线由信转向门外道路，将信收入袖内，迈过门槛。固定机位保持门柱、人物、门外路线可读，让位移改变构图；衣袖随迈步滞后。结束状态是人物站到门外，信已入袖，地点与光源不变。

示例是候选镜头行为，不包含虚构的音乐时间码。口型镜头需单独结合实际人声音频窗口；不能让精细动作占用必要的演唱可见性。

生成片段长度由后端契约决定；交付镜头长度由音乐与表演决定。跨片段动作要显式衔接状态，换模型只转码措辞与参数，人物、空间、动作与光源不随之改变。

## 5. 分层验收与修复

- Prompt Check：采用 PASS / WEAK / RISK / CONFLICT，优先检查动作、空间、机位、来源光线、参考职责和指令冲突，不用形容词数量或“电影感分数”评分。
- 图片验收：核对五官/服装、空间、构图、材质与已选视觉规律。自动检查只能验证结构和记录，视觉结果需要实际观察。
- 动态样片：选能代表全片方法和主要生成难点的一段，检查动作、接触、表演、口型与镜头运动。代表段通过不意味着所有场景已经通过，新增难点需针对性检查。
- 段落审片：检查观众理解、情绪推进、镜头关系与音乐节奏。联系表仅辅助构图和连续性，不代替动态审片。
- Decode Repair：先区分合理适配与真正漂移，最多定位三个主因；人物或材质局部失败用 CHANGE ONLY / PRESERVE EXACTLY；空间、故事或机位结构失败返回 Scene Master。
- 最终交付：视频生成/剪辑审美、音画时间对齐、口型、音质分别记录。原始母带保持独立，分析副本和后端音轨不能替代它。

## 6. 现有代码的开发顺序

### 第一阶段：先解决设计失真

- 将 timeline 歌词窗口与视觉镜头解耦；保留音频时间权威，为视觉镜头建立对音乐段落、歌词范围和切镜依据的引用。
- 取消“歌曲后半段=副歌”的猜测；无结构证据时标记待分析。
- 景别、口型与摄影机动作由导演方案决定，不依赖轮转模板。固定比例是否改为项目配置属于显式流程规则变更，实施时需要同步 Skill、Schema 与门禁。
- 指定导演但没有经过路由的执行决策时，提示缺失；不能静默补通用四轴并宣称已应用导演方法。
- 支持场景级和逐镜级决策，允许某轴明确保留；四轴检查不能强迫轻微强度启用全部方法。

### 第二阶段：建立资产依赖

- 场景母版与关键帧保存来源、职责、版本、检查状态和母版引用。
- 参考语法与场景事实分别保存，最终汇入当前 Scene Master。
- 服装/道具/地点状态建立前后依赖；改动母版或锁时只将依赖产物标记需复核，不静默整片重生成。
- 不靠仅“存在字段”或“命中任一关键词”判定 Scene Master 与参考职责已正确执行。

### 第三阶段：验证生成与剪辑

- 保留模型中立制作包与用户选择的外部适配边界；记录真实请求/回执和素材来源。
- 增加逐素材可用片段、开始/结束状态与剪辑使用区间，生成章节不能直接等于最终镜头。
- 增加段落试剪结果与时间码修复记录；技术报告不能自动宣布审美通过。

上述路线的工具实现见 V1.4.0；它们检查结构、依赖和剪辑行为，不能自动替代艺术分析、视觉审查、后端原生适配或保证传播效果。

## 7. 预期交付

音乐结构与情绪表、来源台账、全片导演方案、导演与参考视觉决策、Continuity Bible、场景母版、Scene Masters、分镜关键帧与 Shot Deltas、模型中立视频制作包、素材与剪辑表、分层验收及定向修复记录。

资料按项目复杂度保留；不把所有档案头或无关字段塞进每镜提示词。全流程能说明：每个视觉决定从哪里来，如何进入关键帧和视频，如何在成片中被检查。
