# 对标氛围转译与提示词细化

适用于用户提供对标视频，并要求“按这个感觉”“氛围接近”“照对标走”的 MV。它补充现有序列工作流，不替代时间轴、人物锁、Scene Master、后端契约或真实动态审片。

## 拉片后先确定本片必须保留的感觉

不要把对标简化成“古装人物＋地下说唱＋群众＋DJ”。题材、镜头类别齐全，仍可能得到完全不同的作品。

按实际可观察证据记录下表。每项包含来源区间、观察事实、在本片怎样保留、进入哪些镜头及回片观察条件；未知项明确写未知，不以记忆或想象补成拉片事实。记录放进现有参考分析与序列设计文档，不创建一套虚构的机器 schema。

| 维度 | 应记录的可执行关系 |
| --- | --- |
| 空间与舞美 | 场所尺度、层高、封闭程度、群众围合密度、选手与群众距离、DJ位置、通道、前景与背景的占画比例；空间如何给表演压力 |
| 灯光与曝光 | 可见及可推断光源的位置、方向、软硬、脸和背景的明暗关系、眼睛可读程度、哪些材质反光；不要编造未测量的色温或光比 |
| 色彩与材质 | 主色来自何种服装、墙面与灯具，肤色与暗部如何呈现，木、布、金属的实际响应；不靠通用滤镜改写 |
| 摄影与构图 | 摄影机离表演者多近、高度、视角压迫程度、前景遮挡、双方同框关系、焦点与手持幅度；“正反打”须落实为真实站位与视线 |
| 人物表演与调度 | 谁主动、谁承压、动作幅度、眼神落点、近身距离和进退如何改变，夸张程度；不能只照搬服饰 |
| 群众与现场感 | 群众在听谁、何时理解、何时笑或吆喝，不同人的先后反应；人群与表演者是否处在同一可读空间 |
| 剪辑与声音 | 攻击如何接对手或群众反应、反应怎样接下一句、何处回全场或DJ、何处保持完整演唱；器乐、搓碟、停顿、环境声与画面动作的关系 |

用户要求跟随对标时，上述已观察到的关键气质默认作为设计约束。人物、歌词、明确指定的造型等用户事实仍优先；对标中的姓名、文字、水印和无关内容不迁移。开放部分允许适配，但不能无说明把压迫的近身围场换成宽敞展演，把低照度现场改成均匀商业布光，再声称只是“提升美术”。

必要的改动须写明：保留了哪种感受、改变了哪个物理条件、为什么仍能保留其作用。若实际效果已转向另一种氛围，按偏离处理，不能靠导演姓名、风格词或“高级感”解释为成功。ZY 导演库只细化兼容的开放决定，不取代对标。

## 每镜提示词：细节充分且有职责

“加满细节”指让模型不必猜测关键拍摄决定，不是堆满形容词、器材名和反复禁令。沿用现有六段式和后端编译规则，按本镜需要展开：

- **共同底座**：本镜实际出现的人物身份与衣装、同一场地的可见地标、固定光位、对标中本镜要继承的具体气质。重申关键锁，排除人物设定图的白底与文字。
- **空间与美术**：前中后景分别是什么，人物和群众的相对位置、可用路径、道具尺度及材质；细节服务表演，不让装饰淹没视觉中心。
- **灯光与画面**：主光从哪个实际方向照到哪侧脸，暗面与背景如何保留，肤色、白衣和甲胄高光如何处理；只写实际可执行或明确提出的设计值。
- **表演过程**：本镜开始时的状态、当前动作、目光对象、手与道具接触、句尾或动作后的变化、结束状态。群众写从聆听到理解再回应的过程，不写全员同时欢呼。
- **摄影执行**：物理机位、景别、画框边界、视觉中心、双方的画面方向、移动由谁触发；相邻镜头的视线和动作接点如何承接。
- **声画执行**：谁在唱、谁只听、使用哪段真实音频和歌词、何时允许画外声、道具动作怎样对应声音。DJ搓碟须写触盘、前后转动和切音动作，不能拿旋钮或推子特写替代。
- **切镜与保持**：为何此时离开主唱，反应发生在攻击前还是后，反应需要看懂什么，再接谁。选中的覆盖镜必须是正式定时镜头，不能临时覆盖仍在演唱的主角而不复核该句职责。

逐镜和章节包须保留这些执行事实；不能在汇总时压成“双方激烈battle，群众欢呼，电影感灯光，多机位快切”。后端有提示词长度或引用限制时，先删重复修辞和无关装饰，再合理拆分制作包，不丢人物、空间、灯光、声画和衔接的关键条件。不发明参数来模拟控制力。

## 贴身 Battle 的专项摄影与剪辑

用户要求贴近地下说唱比赛时，主体覆盖以特写、近景、中景、过肩正反打及近距离双人为主。全场镜头负责建立或重新建立关系，不让宽阔场地和远小人物长时间代替正面对抗。画面中的脸、眼神、嘴、手势与对手反应应可读；具体距离、围场密度和受光服从对标。

- 提示词逐镜写出：观看谁、摄影机站哪侧、景别、机位高度、视线对象、前景肩部占比、开始与结束构图、运动触发、切出与切入理由。只写“多机位、正反打、镜头动起来”不合格。
- 按空间和心理距离选用24/35/50mm等焦段行为，分别用于近身环境压力、双方关系和面部表演；焦段是拍摄设计，不是配额。禁止只改焦段标签却仍是相同远距离构图。
- 平视、略仰、略俯须有可放置摄影机的位置，并保持轴线与视线。活动演唱镜头设计可见而克制的推近、拉开、跟随或摇移：写清从何处到何处、由哪个手势或重拍触发、何时停住。不围着人物随机转圈，也不为运动而破坏嘴部可读性。群众和对手反应可用轻微现场呼吸或稳定观察承接，不机械要求每镜同一种运动。
- 主唱、对手反应、群众聆听到吆喝、全场、DJ是同一事件的覆盖。覆盖的数量和镜长一起设计，群众镜头保留完整反应过程，不能为了“丰富”拆成半秒闪片；检查原镜头碎尾、重复回跳、眼神方向和动作状态。
- 明确每句演唱者。关键攻击句及用户指定必须看主唱的区间优先保持表演者在画内；非主唱反应须有正式分镜依据。不能因为歌词仍在响，就把闭嘴的对手误当成正在演唱者，也不能临时插群众遮掉用户要求保留的演唱。
- DJ搓碟使用真实音频条件，明确手指触盘、盘面前后转动和切音动作；回片检查声音事件与可见动作，推子、旋钮或自动转盘不能充当搓碟。用户允许保留的片段可沿用，其余要求全新生成时不得靠旧素材返剪替代。

## 在批量生成前比较实际氛围

先选有代表性的对峙、反应、全场或DJ段落，按当前样片门禁执行；不必机械凑齐类别。将对标相应区间和真实样片用相近观看尺度连续比较，逐项回答：空间压力、人物距离、群众参与、脸与背景光比、材质色彩、表演强度、摄影贴近程度、声音与动作、切镜因果是否仍是用户要求的感觉。

每项写实际相似点、偏离点及返工动作。场景、主光或摄影距离整体偏离时，返回对应上游重做；不能继续批量生成，再靠补群众、加颗粒、换滤镜或多切几刀补救。

群众镜头既要足够丰富，也必须容纳可读的反应过程。保留观看主体、视线和原空间，检查插镜前后是否留下主唱碎尾或无意义回跳。镜长服从实际表演、音乐和对标段落，不把本次项目的秒数或镜头数量变成通用配额。完整演唱、句尾反应和音乐停顿的分配须逐句设计。

这是执行与审片要求，**不是已经新增的自动检测器**。抽帧只能支持静态观察，频谱和节拍检测只能支持信号候选；不能据此宣称完整听看或对标氛围通过。没有实际观看/听辨能力时如实保留未验收项，不伪造批准，也不默认让用户替执行者逐处定位。
