# 参考驱动的电影 MV 序列

新项目执行顺序以[当前实际执行流程](actual-execution-workflow.md)为准；本文件说明对应阶段的细节。

目的：先让一个段落成立，再让全片形成情绪弧线；不是靠导演名字、参考数量或字段齐全认定电影感。

第4步内部先从歌曲与故事确定观看目标，再用电影标注辅助镜头组织，检查具名人物的位置、轴线、动作与信息承接，完成结构选择后执行导演风格化。组织依据进入逐镜提示词、章节beats与全能参考timeline；详细交接与版本约束见[电影语料创作交接](film-grammar-creative-bridge.md)。新计划`creative_workflow.film_grammar_required=true`时，缺少有效结构选择不能完成第4步。

用户提供对标并要求跟随其感觉时，先执行 [对标氛围转译与提示词细化](benchmark-atmosphere.md)。拉片结果必须约束实际场景、灯光、表演、摄影与剪辑，不能只继承题材后重新设计另一种氛围；代表样片须与对应参考区间比较实际效果。

1. 来源：ProjectAdA 提取具体区间的原始景别、摄影、光线、声音标注；未看媒体的数值标签不翻译成想象的画面。MovieChat-SSeg 只提取真实镜头/场景分组，帧区间没有可靠 fps 不转秒，不推断剧情。ZY 读取选定导演的完整方法文件。
2. 转译：来源事实、解释、当前故事的视觉提案分开。记录保留的方法与不照搬的内容。资料缺少画面观察就保持 annotation_only，不能称几百部电影已观看。
3. 编剧和导演：每段目标→阻力→行动→后果，安排观众何时比人物早知道或晚知道。每镜负责一个观看任务；可以有长镜头和同角度延续，不为配额换机位。
4. 摄影与调度：真实坐标、镜头高度、主体起止点和视线。切点注明前镜的出画信息与后镜的入画信息。先建立空间再局部遮挡；改轴必须有空间重新建立的镜头。
5. 美术和灯光：道具是行动节点，光源有位置、用途和可见度预算；不以蓝橙配色、背光雾气代替设计。白旗袍细节和肤色不因风格被毁；人物参考不继承白底和姿态。
6. 剪辑预演：使用原曲，不按生成模型最长时长切音乐。歌词 ASR 时码未经确认仍是待核；节拍检测仅提示，不自行宣布听过歌曲。完整低成本预演须实际观看，记录删镜、延长、移位、换覆盖的具体决定。
7. 有限生成：只生成会改变判断的母版和关键帧。并排检查相邻帧，再看代表段真实运动、人物与道具状态；批准后扩展，逐章审查后才正式剪辑。

新版序列编译保留人工事实到主提示词、关键帧和运动包，并绑定审批依赖。设计文件本身不能签发艺术批准。网页文字/调度示意预演也不是写实动态样片，不能据此声称口型、演技或成片质量已验证。

## 剪辑接点的实际失败教训

编码的CFR、帧数与时间戳通过，仍可能把手或身体的动作剪跳。连续动作覆盖必须看出点、入点及前后动态句柄；同源镜头跳过动作中段、把后态接回前态时，不能只改写成“蒙太奇”就认为成立。记忆/当下的时间关系也必须能从实际序列读出，不能依赖说明文档替画面解释。

关键动作缺失时退回覆盖设计或重新生成，不用补帧、叠化、变速、重复动作或截短反应掩盖。用户要求全新生成时，不得以旧素材返剪或恢复旧版替代。配乐兼容版本须实际核验音轨和播放器支持；保留原母带，无损保存与兼容AAC副本分别标明，不能把有音轨等同于用户端已经听到。
